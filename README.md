# Recall.

Spaced repetition, but make it simple.

A minimal, dark-themed revision tracker to never forget what you learned.

### Features
- Add custom subjects
- Add topics with auto spaced repetition (0 → 1 → 3 → 7 → 15 → 30 days)
- Due Today tracking
- Forgot / Revise Now flow
- Clean mobile-first UI

### Tech
React + Vite + Tailwind + LocalStorage
