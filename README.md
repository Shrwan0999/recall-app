# Recall - Spaced Repetition System

Recall is a productivity tool designed to improve long-term retention for learners. It tackles the problem of forgetting what you study after a few days by implementing the Ebbinghaus Forgetting Curve.

### Core Features
- **Smart Revision Scheduling:** Automatically schedules revisions at 1, 3, and 7 day intervals based on user recall rating.
- **Active Recall Mechanism:** Question-first flashcards to test memory before revealing the answer.
- **Dynamic Dashboard:** Segregates learnings into Today / Overdue / Upcoming for better prioritization.
- **Client-Side Persistence:** Zero backend dependency, entire data managed via LocalStorage for instant performance.
- **Retention Analytics:** Tracks recall accuracy and daily streaks.

### Tech Stack
**Frontend:** React.js, Tailwind CSS
**Core Logic:** Custom spaced repetition algorithm, LocalStorage API

### Why this stands out?
Unlike generic CRUD apps, this project demonstrates understanding of cognitive science principles and their application in frontend logic - a strong point for product-based roles.
